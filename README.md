# OC-Decider

An OpenAI compliant endpoint that improves OpenClaw usefulness by using multiple models to intelligently route and enhance requests.

## Overview

OC-Decider implements a multi-model routing system that:

1. **Analyzes Complexity**: Uses a lightweight, fast model (e.g., GPT-3.5-turbo) to quickly determine the complexity of user prompts
2. **Generates Plans**: For high-complexity queries, uses an advanced thinking model (e.g., GPT-4) to create a structured plan
3. **Enhances Prompts**: Injects the generated plan into the original prompt to guide response generation
4. **Produces Results**: Sends the augmented prompt to the final LLM for a better-structured, more comprehensive response

## Features

- ✅ OpenAI API compatible endpoint
- ✅ Intelligent complexity analysis
- ✅ Automatic planning for complex queries
- ✅ Configurable model selection
- ✅ Streaming support
- ✅ Easy integration with existing OpenAI-compatible tools

## Installation

```bash
# Clone the repository
git clone https://github.com/AidanTheBandit/OC-Decider.git
cd OC-Decider

# Install dependencies
npm install

# Copy and configure environment variables
cp .env.example .env
# Edit .env with your OpenAI API key
```

## Configuration

Create a `.env` file with the following variables:

```env
OPENAI_API_KEY=your_api_key_here
OPENAI_BASE_URL=https://api.openai.com/v1

# Server Configuration
PORT=3000

# Model Configuration
COMPLEXITY_MODEL=gpt-3.5-turbo
PLANNER_MODEL=gpt-4-turbo-preview
DEFAULT_MODEL=gpt-4-turbo-preview

# Complexity Threshold (1-10, where 10 is most complex)
HIGH_COMPLEXITY_THRESHOLD=6
```

## Usage

### Starting the Server

```bash
npm start
```

The server will start on the configured port (default: 3000).

### API Endpoints

#### Chat Completions
```
POST /v1/chat/completions
```

This endpoint is fully compatible with the OpenAI Chat Completions API.

**Example Request:**
```bash
curl http://localhost:3000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4-turbo-preview",
    "messages": [
      {
        "role": "user",
        "content": "Create a comprehensive guide for building a microservices architecture with Docker, Kubernetes, and implement CI/CD pipelines"
      }
    ]
  }'
```

#### Health Check
```
GET /health
```

Returns the service status.

#### Models List
```
GET /v1/models
```

Returns available models.

### How It Works

1. **Simple Queries** (complexity < 6/10):
   - Directly processed by the default model
   - Fast response with minimal overhead

2. **Complex Queries** (complexity ≥ 6/10):
   - Complexity analyzed by lightweight model
   - Plan generated by advanced thinking model
   - Plan injected into prompt
   - Final response generated with enhanced context

### Using with OpenAI SDK

You can use OC-Decider as a drop-in replacement for the OpenAI API:

```javascript
const OpenAI = require('openai');

const client = new OpenAI({
  apiKey: 'not-needed-for-local',
  baseURL: 'http://localhost:3000/v1'
});

const response = await client.chat.completions.create({
  model: 'gpt-4-turbo-preview',
  messages: [
    { role: 'user', content: 'Your complex query here' }
  ]
});

console.log(response.choices[0].message.content);
```

## Architecture

```
User Request
     ↓
[Complexity Analyzer] (Fast Model: GPT-3.5-turbo)
     ↓
Is High Complexity?
     ↓
   Yes → [Planning Generator] (Advanced Model: GPT-4)
     ↓
[Prompt Injection]
     ↓
[Final LLM] (Configured Model)
     ↓
Response to User
```

## Benefits

- **Better Responses**: Complex queries get structured planning for more comprehensive answers
- **Cost Efficient**: Simple queries skip planning, reducing API costs
- **Fast for Simple Tasks**: Lightweight model analyzes complexity quickly
- **Transparent**: Standard OpenAI API format means easy integration
